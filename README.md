# Student Registration System 🎓

Bu proje, **C#** ve **Windows Forms** kullanılarak geliştirilmiş, öğrenci verilerinin yönetilmesini sağlayan kapsamlı bir kayıt otomasyonudur.

## 🚀 Proje Hakkında
Uygulama, temel **CRUD (Create, Read, Update, Delete)** işlemlerini gerçekleştirerek veri yönetiminin nasıl yapıldığını demonstre eder. Öğrenci bilgilerinin sisteme girilmesi, listelenmesi ve düzenlenmesi işlevlerini içerir.

## ⚙️ Özellikler
* **Öğrenci Ekleme:** İsim, Numara, Bölüm gibi bilgilerin sisteme kaydedilmesi.
* **Listeleme:** Kayıtlı öğrencilerin `DataGridView` veya liste üzerinde görüntülenmesi.
* **Silme/Güncelleme:** Mevcut kayıtların düzenlenmesi veya sistemden kaldırılması.
* **Veri Doğrulama:** Boş alan veya hatalı giriş kontrolü.
